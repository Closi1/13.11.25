


# P2P Чат

Простой мессенджер, не требующий подключения к глобальной сети для свойе работы.

---

## 🎯 Цель проекта

Проект закрывает потребность группы 1ИСД в средствах коммуникации. Отрабатывается навык использования Git и VS.

---

## 🛠️ Технологии и инструменты

Список используемых технологий, языков программирования, фреймворков, библиотек и инструментов:

- Python 3.10+
- Tkinter
- Git / GitHub
